# Roadmap

The roadmap is a learning guide, not a fixed contract. Each stage should remain small enough to understand and verify.

## Current milestone

- [x] v0.0.0 — Initialize the Rust project and run the starter program.
- [x] v0.0.1 — Open and run a basic application window (verified on macOS).
- [x] v0.0.2 — Add an editable address bar (verified on macOS).

## Browser prototype

- [x] v0.0.3 — Implement basic HTTP/HTTPS requests from the address bar; bare domains default to HTTPS (verified on macOS).
- [ ] v0.0.4 — Display basic HTML.
- [ ] v0.0.5 — Add basic HTML rendering.
- [ ] v0.0.6 — Add basic CSS support.
- [ ] v0.0.7 — Add links and navigation controls.
- [ ] v0.0.8 — Enforce temporary-only history, cookies, cache, and site storage.
- [ ] v0.0.9 — Add request filtering and basic ad/tracker blocking.
- [ ] v0.1.0 — Reach a minimal, genuinely usable browser prototype.

## Later possibilities

JavaScript, improved CSS and rendering, downloads, local bookmarks, multiple windows, permissions, security hardening, developer tools, performance work, and release packaging for macOS, Linux, and Windows.

The sequence may change as we learn what is practical. A complete modern browser engine is not assumed to be feasible to build from scratch.
